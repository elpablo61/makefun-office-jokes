A make.fun entry for [One-Line Office Jokes](https://make.fun/bounty/u-markk-st-one-line-office-jokes-a51f2bcc):
one funny line about office life, 199 characters or fewer, that lands
entirely on its own.

The program (`main.ts`, Node 22) writes the line to
`${MAKEFUN_OUTPUT_DIR ?? "/output"}/entry.txt`. The line is a micro-anecdote
that sounds true: a 30-minute meeting runs 58, and the minutes assign the
follow-up to Agus — who left in March.

Run locally:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/office-jokes-out node main.ts
cat /tmp/office-jokes-out/entry.txt
```
